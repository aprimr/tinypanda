TinyPanda is available as a prebuilt binary for **Linux**, **macOS**, and **Windows**.
This page covers the latest release, earlier versions are available on the [releases page](https://github.com/aprimr/tinypanda/releases).

## Linux

1. Download the latest release.

```bash
curl -LO https://github.com/aprimr/tinypanda/releases/latest/download/tinypanda-linux
```

2. Make the binary executable.

```bash
chmod +x tinypanda-linux
```

3. Move it to `/usr/local/bin` and rename it to `tinypanda`.

```bash
sudo mv tinypanda-linux /usr/local/bin/tinypanda
```

## Windows

1. Download `tinypanda-windows.exe` from the [latest release](https://github.com/aprimr/tinypanda/releases/latest) or [Download](/download) page.

2. Rename it to `tinypanda.exe`.

3. Move it to a folder, for example:

```text
C:\TinyPanda
```

4. Add `C:\TinyPanda` to your system `PATH`.

## Verify the installation

Open a new terminal and run:

```bash
tinypanda --version
```

If TinyPanda is installed correctly, the installed version will be displayed.
